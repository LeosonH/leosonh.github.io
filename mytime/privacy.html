MyTime — Timezone Converter

Privacy Policy · Last updated October 2026

MyTime collects no personal data, sends nothing to any server, and has no analytics or tracking of any kind.

Overview

MyTime is a browser extension that finds times written on the web pages you visit, like “3pm ET” or “14:00 UTC”, and shows them in the timezone you choose. All functionality runs entirely within your browser. Nothing you read or do with the extension is transmitted, logged, or shared.

Data We Collect

We collect no data. Specifically:

  • No browsing history or page content is recorded — page text is read on your device only to find times, and is never stored or sent anywhere
  • No personal information is collected at any point
  • No analytics, telemetry, or crash reporting is in place
  • The extension makes no network requests at all

Settings Storage

MyTime stores three settings using Chrome's extension storage (chrome.storage.sync):

  • Whether MyTime is switched on
  • The timezone you chose, or “local time”
  • Your popup style (Minimal or Airport)

These settings:

  • Are never transmitted to any server operated by MyTime or its developer
  • May be synced between your own devices by Chrome, if you have Chrome Sync turned on
  • Can be cleared entirely by removing the extension

Permissions

MyTime requests only the permissions it needs to work:

  • storage Used to remember your on/off switch, chosen timezone, and popup style.
  • scripting Used to run MyTime's page script while you have it switched on, including in tabs that were already open when you switched it on. It is removed from new pages when you switch MyTime off. No scripts are loaded from external sources — all code is bundled within the extension package.
  • Site access (all sites) Times appear on any website — emails, event pages, docs, chat — so MyTime needs to read page text wherever you browse to find and convert them, without you clicking on each page. It only reads visible text and rewrites times in place, on your device.

Remote Code

MyTime executes no remote code. All JavaScript, CSS, and assets are fully self-contained within the extension package. This complies with Chrome's Manifest V3 requirements and means the extension's behaviour cannot be changed without a published update that you can review.

Third Parties

MyTime has no third-party integrations, SDKs, advertising networks, or data brokers. No data is shared with any third party because no data is collected in the first place.

Changes to This Policy

If this policy is updated in a future version of the extension, the updated date at the top of this page will reflect the change. Continued use of the extension after an update constitutes acceptance of the revised policy.
